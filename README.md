# Power BI Financial Dashboard

This project contains sample financial data and guidelines to build a dashboard in Power BI.

## Dataset

- `financials.csv` – weekly financial performance data for different departments.

## Visualization

- `profit_by_department.png` – bar chart showing total profit by department.

## Description

This sample data can be loaded into Power BI Desktop to build dashboards exploring revenue, expenses and profit trends.  The included bar chart demonstrates how profit varies across departments.  From here you can expand the analysis with additional charts such as revenue vs. expenses or profit over time using DAX and Power BI’s interactive visuals.
